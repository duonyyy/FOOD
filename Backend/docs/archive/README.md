# Tài liệu Lưu trữ (Archive)

Thư mục này chứa các tài liệu kế hoạch refactor, đồ thị phụ thuộc và báo cáo kiểm tra codebase lịch sử đã được hoàn tất:

- `DELIVERY_REFACTORING_PLAN.md`: Kế hoạch tái cấu trúc feature Delivery và Shipper profile.
- `ORDERS_REFACTORING_PLAN.md`: Kế hoạch chuyển đổi Orders sang mô hình Role-based.
- `ORDERS_DEPENDENCY_GRAPH.md`: Phân tích đồ thị phụ thuộc của feature Orders.
- `PROJECT_CODEBASE_AUDIT.md`: Báo cáo kiểm tra codebase giai đoạn đầu.
- `SHARED_TYPES_EXTRACTION_PLAN.md`: Kế hoạch trích xuất types thuần vào `src/shared`.
- `SIMPLIFY_CONTRACTS_PLAN.md`: Kế hoạch tinh giản ports & contracts nội bộ.
- `SNAPSHOT_REMOVAL_PLAN.md`: Kế hoạch loại bỏ snapshot trung gian.

Tài liệu chuẩn mực hiện hành của dự án:
- Chuẩn kiến trúc toàn hệ thống: [`Backend/AGENTS.md`](../../AGENTS.md)
- Chuẩn nghiệp vụ feature: [`src/features/README.md`](../../src/features/README.md)
- Tiêu chí nghiệm thu feature: [`src/features/REFACTOR_REQUIREMENTS.md`](../../src/features/REFACTOR_REQUIREMENTS.md)
